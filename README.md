# Instant_Summarizer
Developed a fast and lightweight web app using Python and Streamlit to generate text summaries from pasted or uploaded content. It uses a custom word frequency–based algorithm with no machine learning dependencies, supports multiple file types, and offers dynamic summary length and style options.
